# Nilafer's Moonlit Bloom

Create a highly emotional, premium, cinematic birthday website dedicated to **Nilafer**.



### Core Theme



The entire website should be inspired by the meaning of her name: **Blue Water Lily**.



The design should feel like a magical night garden where blue water lilies bloom under moonlight. The experience should be elegant, dreamy, romantic, and artistic rather than childish or overly colorful.



### Design Direction



* Premium luxury aesthetic

* Moonlit lake atmosphere

* Floating blue water lilies

* Soft water ripples

* Gentle glowing particles

* Deep navy blue, sapphire blue, silver, and soft white color palette

* Smooth animations throughout the website

* Modern typography with elegant serif headings and clean sans-serif body text

* Glassmorphism and subtle glow effects

* Fully responsive for desktop, tablet, and mobile

### Technical Requirements



* React + Next.js

* Framer Motion animations

* Smooth scrolling

* Performance optimized

* Fully responsive

* Lazy loaded images

* Premium transitions

* Dark mode aesthetic

### Overall Goal



The website should feel less like a normal birthday page and more like a beautiful digital experience inspired by a rare blue water lily blooming under moonlight. Every section should tell a story and make Nilafer feel cherished, appreciated, and celebrated.
